Guia de instalação

Sankhya Repo Updater

Um pacote que verifica sozinho, todo dia, se os módulos Sankhya têm versão nova — e atualiza sem ninguém precisar lembrar ou pedir. Esta versão se configura sozinha: não precisa editar nenhum arquivo, nem pedir ajuda pra ninguém, nem lidar com .ps1 — é tudo .bat.

Baixar sankhya-repo-updater-template.zip
Descobre sozinho quais repositórios Sankhya existem no computador — não precisa informar caminho de nada
Uma tarefa agendada roda 1x por dia sozinha, testando a VPN antes de tentar qualquer coisa
git pull --ff-only em cada repositório — só avança quando é fast-forward, nunca força merge
Um atalho na área de trabalho pra rodar na hora, quando quiser (ex: assim que conectar a VPN de manhã)
Log de cada execução e aviso na tela quando algo for atualizado, guardado ou der erro

Antes de começar

  • Windows com PowerShell (já vem instalado) e Git
  • Os repositórios que você quer manter atualizados já clonados (git clone) em algum lugar do computador
  • VPN da Sankhya (FortiClient) configurada e funcionando
  • FortiClient fixado na barra de tarefas (clique direito no ícone dele → "Fixar na barra de tarefas") — só é obrigatório se for usar a VPN automática opcional abaixo
  • O arquivo sankhya-repo-updater-template.zip — baixe aqui no Drive
Caminho rápido recomendado

Instalação automática

Você não edita nada. O instalador varre o computador, encontra os repositórios sozinho e já deixa tudo funcionando.

1

Extraia o pacote

Baixe o sankhya-repo-updater-template.zip no Drive e descompacte em qualquer pasta — não precisa ser dentro da pasta dos projetos.

2

Dê 2 cliques em Instalar-Automatico.bat

Uma janela preta de console abre, mostra o progresso, e ao final aparece uma caixa de mensagem com o resultado. Aperte qualquer tecla pra fechar o console quando terminar.

ℹ Não tem nenhum arquivo .ps1 nesta pasta — todo o pacote é só .bat, que roda normalmente com clique duplo, sem abrir editor de texto nem exigir configuração extra do PowerShell.

O script procura pastas com repositório git cujo remoto aponte para gitlab.sankhya.com.br. Pode levar 1–2 minutos na primeira vez.

3

Confira o resumo

Uma janela mostra quais repositórios foram encontrados e configurados, o horário da checagem diária e o nome do atalho criado na área de trabalho. Pronto — nada mais a fazer.

Caminho alternativo controle manual

Instalação manual

Só use esta via se quiser escolher exatamente quais pastas entram, em vez de deixar o instalador descobrir sozinho.

1

Edite o config.json

Preencha reposRoot (pasta que contém os repositórios) e repoNames (nomes das pastas dentro dela) — ou, se os repositórios estiverem espalhados, preencha repoPaths com uma lista de caminhos completos.

2

Rode o instalador manual

Dê 2 cliques em install.bat.

3

Habilite caminhos longos, se for avisado

Só necessário se algum repositório tiver arquivos de build com caminho muito comprido. Requer PowerShell como Administrador, 1x só:

New-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem" `
  -Name LongPathsEnabled -Value 1 -PropertyType DWord -Force

No dia a dia

Antes de mexer em qualquer repositório, o script testa se consegue alcançar o host git configurado. Se a VPN estiver desconectada, por padrão ele não tenta nada e avisa isso especificamente — em vez de um erro genérico, a notificação diz pra conectar a VPN e usar o atalho manual depois (dá pra automatizar até essa parte, veja "VPN automática" abaixo). O histórico de cada execução fica em logs\update-AAAAMM.log, dentro da própria pasta do pacote.

Segurança: alterações não commitadas

Quando um repositório tem mudanças que ainda não foram commitadas, o script precisa decidir o que fazer com elas antes de atualizar. Essa escolha é o campo discardMode no config.json.

padrão do pacote

"stash"

Guarda as mudanças com git stash push -u antes de atualizar. Reversível — recupere depois com git stash pop. Fique aqui se não tiver certeza de qual usar.

use com cautela

"hard"

Roda git reset --hard + git clean -fd. Apaga qualquer alteração não commitada para sempre, sem volta. Só use se tiver certeza de nunca deixar trabalho sem commit nesses repositórios no horário agendado.

VPN automática

Por padrão, quando a VPN está desconectada o pacote só abre a janela do FortiClient e mostra o aviso — você clica em "Conectar" você mesmo. Dá pra ligar um modo em que ele clica sozinho.

opcional · desligado por padrão "vpnAutoConnect": true

Quando ligado, o pacote abre o FortiClient e clica em "Conectar" sozinho toda vez que a VPN estiver desconectada — no atalho manual e na tarefa agendada. Só completa a conexão se sua sessão SSO já estiver autenticada (o mesmo fluxo sem senha que você já usa); caso contrário, para aí mesmo sem travar nada.

FortiClient fixado na barra de tarefas
Sessão SSO já autenticada no navegador

Se algum dos dois não se aplicar numa execução, ele cai de volta no comportamento padrão (abrir a janela, avisar) — nunca quebra o resto do pacote.

Se algo der errado

O antivírus reclamou do .bat usando certutil

Os .bat deste pacote usam certutil -decode (ferramenta nativa do Windows) pra reconstruir, num arquivo temporário em %TEMP%, o script que efetivamente roda — e apagam esse arquivo temporário logo depois. É uma técnica válida e comum, mas algum antivírus mais agressivo pode estranhar por padrão. Se acontecer, adicione uma exceção para a pasta do pacote.

Notificação "VPN desconectada"

Normal — o script detectou que não alcança o host git configurado. Conecte a VPN e rode o atalho manual.

"git pull --ff-only falhou (provável divergência)"

Seu branch local e o remoto divergiram (ex: alguém reescreveu histórico). O script não força nada — resolva manualmente com git pull ou git rebase naquele repositório.

"Filename too long" durante a atualização

Limite de caminho do Windows. Aplique o passo de LongPathsEnabled da instalação manual. Até lá, o script só pula aquele repositório naquele dia, sem quebrar nada.

O instalador automático não encontrou nenhum repositório

Confirme que os projetos já foram clonados com git clone, e que o remoto origin deles aponta para o host git configurado (rode git remote -v dentro da pasta do projeto pra conferir). Se o host for outro, abra um "Prompt de Comando" nesta pasta e rode Instalar-Automatico.bat -GitHost "seu.git.host".

Liguei vpnAutoConnect e o clique não acerta o botão

O cálculo do clique usa a área de conteúdo da janela do FortiClient como referência, então costuma se ajustar sozinho entre resoluções — mas em telas muito fora do padrão ainda pode errar por poucos pixels. Se isso acontecer, desligue vpnAutoConnect de volta pra false: o pacote continua funcionando normalmente, só sem essa parte.

Desinstalar

Dê 2 cliques em uninstall.bat. Remove a tarefa agendada e o atalho da área de trabalho (os logs ficam, se quiser apagar é manual).
